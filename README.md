# IL SALONE · Georgina Ovando

Sitio web estático (HTML + CSS + JS, sin dependencias) del salón de belleza **IL SALONE Georgina Ovando**.

## Estructura
```
index.html        Página principal
css/styles.css    Estilos y paleta de colores
js/main.js        Menú móvil y animaciones
assets/logo.jpg   Logotipo
```

## Paleta (tomada del logotipo)
| Color | Hex | Uso |
|---|---|---|
| Rosa perla | `#F1E4E3` | Fondos |
| Rosa polvo | `#DEC2BF` | Fondos / bordes |
| Dorado | `#9B7C4D` | Acentos, títulos |
| Bronce | `#6C4E25` | Botones |
| Café tinta | `#3B2A1C` | Texto |
